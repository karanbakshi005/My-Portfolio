## Run locally
1. Install Node.js LTS.
2. Open this folder in VS Code.
3. Run:
   ```bash
   npm install
   npm run dev
   ```
4. Open the local URL printed by Vite.

## Before publishing
- Add your LinkedIn profile URL when available.
- Prepare and review your resume. No fake resume download is included.
- Review project descriptions and ensure you are allowed to share them publicly.
- Add verified screenshots, public demo links, and measurable outcomes only when confirmed.
- Confirm all listed technical skills match your actual proficiency.
- The contact form opens a pre-filled email draft in the visitor's default email app; it does not submit to a server.
